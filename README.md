# Python Mini Projects Collection 🐍

Bu repozitoriyada müxtəlif məntiqi məsələlərin həlli və praktiki tətbiqlər üçün yazılmış kiçik Python skriptləri toplanmışdır.

## 📁 Proqramlar Haqqında

Repozitoriya üç əsas Python skriptindən ibarətdir:

### 1. BMI (Bədən Kütlə İndeksi) Hesablayıcı
İstifadəçidən kilo və boy ölçülərini daxil etməyi tələb edir, BKI-ni hesablayır və uyğun çəki kateqoriyasını (`Underweight`, `Normal Weight`, `Overweight`, `Obese`) ekrana çıxarır.

### 2. Çin Zodiak (Chinese Zodiac) Təyin Edicisi
İstifadəçinin doğum ilini qəbul edərək həmin ilin Çin təqvimində hansı heyvan bürcünə (`Monkey`, `Rooster`, `Dog` və s.) uyğun gəldiyini `while` dövrü (loop) vasitəsilə hesablayır.

### 3. Ad günü Təxmin Edən Oyun (Birthday Guessing Game)
İkili sistem (binary) məntiqinə əsaslanan bu proqram, istifadəçinin doğum gününü müxtəlif rəqəm dəstləri (`Set 1-5`) vasitəsilə suallar verərək tapır.
